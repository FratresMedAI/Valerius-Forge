# Valerius Forge

Turn one plain-English sentence into a brief a coding agent can follow.

Two skills live in this pack:

- **Valerius agent prompt.** For an assistant, chatbot, or system prompt.
- **Valerius project brief.** For an app, tool, or build.

Fratres X AI. The same forge as [Valerius](https://valerius-forge.vercel.app). The buyer's agent does the work. No API key is sent to Fratres.
